# 🧹 Sarva-Sarathi – Maid Management System  

A simple web-based system to manage maid information, attendance, salary, and work assignments.  
The platform helps households or small agencies maintain records in an organized and efficient way.

---

## 🔗 Live Project  
🚀 **Live Demo:** https://maidmanagement.rf.gd/

---

## 📌 Features  
- Add, update, and manage maid profiles  
- Track attendance and schedules  
- Manage salary information  
- Search & filter maid details  
- Admin login dashboard  
- Clean and simple UI  

---

## 🛠 Tech Stack  
- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** PHP  
- **Database:** MySQL  
- **Hosting:** InfinityFree (Free hosting)
